# Quiet Scan

vFlat 계열의 핵심 문서 스캔 흐름을 구현한 한국어 **로컬 브라우저 MVP**입니다. Quiet Capture 디자인과 iPhone/Pixel 기기 미리보기 런타임을 유지합니다. 네이티브 iOS/Android 앱 또는 전체 vFlat 기능 복제품은 아닙니다.

## 구현된 기능

- 브라우저 카메라 연결, 실제 프레임 촬영, 실시간 경계 표시와 안정된 경계 기반 자동 촬영. 지원 기기에서 플래시 제어.
- JPG/PNG/WEBP 가져오기, 경계 추정, 원근 보정, 수동 모서리 조정, 6개 이미지 필터.
- 책 이미지의 중앙 기준 좌우 분할, 최대 20페이지, 회전·순서 변경·삭제·추가.
- 실험적 로컬 책 보정: 글줄 기반 곡률 제안/수동 강도·방향 조정, 가장자리 피부색 후보/수동 영역 가리기, 전후 미리보기, 적용 및 되돌리기. 되돌리기용 이미지는 문서와 함께 저장됩니다.
- Tesseract.js를 통한 한국어·영어 OCR, 실제 줄 좌표와 0–1 신뢰도 저장. TXT 다운로드·클립보드 복사.
- 이미지 PDF 또는 한글 글꼴/보이지 않는 OCR 텍스트를 포함한 검색 가능한 PDF. 고화질/압축 품질 선택과 JPG 다운로드.
- IndexedDB 문서 저장·재열기·삭제, 제목·태그·OCR 본문 검색, 생성/수정 날짜 관리.
- 기기 미리보기, 모바일 스크롤·키보드·BottomSheet 런타임 보존.

사진·OCR 텍스트·PDF는 브라우저 안에서 처리합니다. OCR 엔진/언어 파일/글꼴은 같은 앱 서버에서 제공하며 외부 AI 서비스로 문서를 보내지 않습니다. 저장소는 **암호화되지 않았고 브라우저/주소별로 분리**됩니다. 브라우저 데이터 삭제나 저장소 자동 정리로 문서가 사라질 수 있으므로 중요한 문서는 PDF로 백업하세요. 샘플 체험은 명시된 샘플 이미지를 실제 처리하며 가짜 OCR 텍스트를 만들지 않습니다.

## 제한과 RFP 범위

RFP의 핵심 MVP와 로컬 책 보정을 구현했습니다. 경계 추정은 Sobel 기반 휴리스틱이며 검출 실패 시 전체 이미지를 사용합니다. 자르기 좌표가 교차하면 거부합니다. 책 분할은 중앙 이등분입니다. 책 보정은 펼친 책의 완전한 3D 곡면 복원이 아니라, 선택한 책등 방향에 집중된 제한적인 2D 수직 변위입니다. 글줄 근거가 부족하면 자동 제안을 하지 않으며 수동 조정할 수 있습니다.

손가락 후보는 가장자리 피부색 규칙으로 찾으므로 종이·사진·로고를 오인하거나 손가락을 놓칠 수 있습니다. 사용자가 선택한 사각형만 주변 밝은 종이색으로 덮습니다. **가려진 글자·질감은 복원하지 않습니다.** 자동 책등 검출·학습 기반 손가락 분할·고급 그림자 복원은 아직 없습니다. OCR 결과는 오인식이 있을 수 있습니다.

가리기는 개인정보 영구 삭제를 위한 보안 마스킹 도구가 아닙니다. 테두리가 부드럽게 혼합되고 되돌리기용 원본도 저장되므로 민감한 정보를 제거했다고 가정하지 마세요.

스캔 미리보기의 **책 보정**에서 조정 → 보정 미리보기 → 이 결과 적용 순서로 사용합니다. 후보는 선택 전까지 적용되지 않습니다. 조정값을 바꾸면 미리보기를 다시 만들어야 합니다. 페이지의 **책 보정 되돌리기**는 저장/다시 열기 후에도 사용할 수 있습니다. 적용/되돌리기/회전/자르기는 기존 OCR을 무효화하므로 텍스트 추출을 다시 실행하세요. 회전·자르기 후에는 이전 좌표계의 책 보정 되돌리기가 사라집니다.

폴더 트리, 기존 PDF 가져오기/병합, 클라우드 동기화·인증·암호화, AI 요약·RAG, 네이티브 앱 패키징은 후속 단계입니다. 별도 평가 데이터셋이나 실기기 검수를 하지 않았으므로 경계 검출 95%, OCR 3초 등 RFP 성능 목표 달성을 주장하지 않습니다.

입력은 파일당 15MB/30MP, 처리 이미지는 긴 변 2200px, 문서당 20페이지와 이미지 합계 100MB로 제한합니다. OCR은 페이지별 90초 제한, 저장 OCR 텍스트는 합계 25만 자 제한입니다.

책 보정 분석은 긴 변 800px, 실제 보정은 2200px로 제한합니다. 최대 변위는 페이지 높이의 6%, 가림 영역은 최대 6개·영역당 15%·총 25%이며 겹치는 영역을 거부합니다. 주변 종이색을 찾지 못하면 가리지 않습니다. 저장 용량 제한은 되돌리기용 이미지도 포함합니다.

## 실행과 검증

Node.js 22.12 이상을 사용합니다.

```sh
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 4183 --strictPort
npm run build
npm run check:runtime
npm run test:sites
npm run test:runtime
npm run test:production
```

카메라는 HTTPS 또는 localhost가 필요합니다. 사진 가져오기는 카메라 없이도 사용할 수 있습니다. Playwright Chromium이 필요하며, 자동 테스트는 생성한 문서 이미지와 가상 카메라를 사용합니다. 실기기 권한·초점·플래시 품질은 별도 검수 대상입니다.

앱 화면은 `src/Prototype.tsx`, 스타일은 `src/prototype.css`, 처리 엔진은 `src/scanner/`에 있습니다. `src/mobile/` 및 기기 프레임은 보호 런타임입니다. `npm run build`는 기존 Sites/Worker 포맷을 보존하지만 실제 배포는 하지 않습니다.
