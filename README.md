# Quiet Scan

vFlat 계열의 문서 스캔 경험을 탐색하는 한국어 모바일 **UI 프로토타입**입니다. 선택한 Quiet Capture 시안을 바탕으로 React, TypeScript, Vite를 사용합니다.

## 현재 구현

- 책/문서/자동 모드, 플래시 및 자동 촬영 설정 상태
- 샘플 촬영 → 처리 시뮬레이션 → 페이지 미리보기
- 책 모드 2페이지, 문서 모드 1페이지 추가; 최대 20페이지
- 페이지 선택, 수평 스크롤, 이미지 표시 필터
- OCR 샘플 표시와 실제 클립보드 복사
- PDF 내보내기 예정 기능 안내
- iPhone / Pixel 미리보기 및 모바일 키보드 런타임

실제 카메라·갤러리 접근, 문서 경계 검출, 원근/곡률 보정, OCR 엔진, PDF 생성, 문서 저장·검색은 아직 구현하지 않았습니다. 사진과 OCR 텍스트는 고정 샘플입니다. 내보내기는 파일을 만들지 않습니다. 페이지와 설정 상태는 메모리에만 있으며 새로고침하면 초기화됩니다. 서버 업로드나 동기화는 없습니다.

## 실행과 검증

Node.js 22.12 이상을 사용합니다.

```sh
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 4183 --strictPort
npm run build
npm run check:runtime
npm run test:sites
npm run test:runtime
```

브라우저 테스트에는 Playwright Chromium 설치가 필요합니다. 앱 코드는 `src/Prototype.tsx`, 스타일은 `src/prototype.css`에 있습니다. `src/mobile/`과 기기 프레임은 보호 런타임이며 `AGENTS.md` 지침을 따릅니다.

## 다음 구현 단계

실제 촬영과 이미지 가져오기, 문서 검출/원근 보정, 온디바이스 한국어·영어 OCR, 검색 가능한 PDF 생성, 로컬 문서 저장·검색 순서로 연결합니다. 현재 시뮬레이션을 인식률 또는 스캔 성능 평가로 사용하지 않습니다.

## 보안

외부 연결 제한 CSP, React 기본 텍스트 이스케이프, 클립보드 오류 처리, 페이지 수 제한을 적용했습니다. 의존성 보안 패치와 검사 내역은 `SECURITY.md`를 확인하세요. 개발 서버는 로컬 전용으로 실행하고 운영 배포에 사용하지 않습니다.

`design-qa.md`는 최초 UI 프로토타입의 시각 검수 기록입니다. 보안 정리 이후의 실제 기능 완성 여부를 보증하지 않습니다.
